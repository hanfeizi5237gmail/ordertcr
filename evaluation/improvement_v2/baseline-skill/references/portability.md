# 可移植使用与能力边界

`SKILL.md`是普通Markdown：支持原生技能导入的Agent可加载目录；不支持的宿主可将该文档与需要的`references/`作为工作指令。技能没有Codex插件、特定模型API、云服务或本机绝对路径依赖。复制包时带上脚本、资产和引用文档，但不要复制真实运行注册表、原始订单、客户身份和已生成账本。

| 宿主能力 | 可交付结果 | 不可声称 |
|---|---|---|
| 文本与目录可读，且具备Excel写入及原生批注 | 按业务规则生成人工可审订单；经实称和财务口径确认后再输出结算 | 未经实际导入验收就说系统接受 |
| Python 3.10+、`openpyxl>=3.1,<4`、本地文件读写 | 运行`python scripts/order_mapping.py --help`核对CLI，使用确定性校验及xlsx导出 | 已在另一Agent或设备上验证兼容 |
| 仅能读文本或表格，无法运行脚本/写原生批注 | 结构化项目和候选、问题清单或CSV草稿 | 已产出满足颜色及原生批注的标准xlsx，或可直接导入财务系统 |
| 无持久目录注册表和快照 | 要求恢复最近状态或重新提供当前目录，再处理新批次 | 知道别的独立设备“最新版” |

运行环境须自行具备依赖；执行器**不自动联网或安装依赖**。若无法使用openpyxl，可让宿主自己的Excel工具实现同一数据契约，并在保存后复读批注、颜色与计算结果；输出缺少原生批注时必须明确未达标。来源目录可随用户明确更新而替换，旧版本及历史文件保留用于追溯；没有云同步服务或跨设备状态保证。

示例JSON展示字段结构而不授权真实公司或计价前提。其他宿主需要校验自己的文件读取、代码执行、xlsx导出、原生批注及重复运行能力；千问办公和WorkBuddy的真实兼容性只能在对应环境运行后报告。任何线上订单系统写入、支付或财务入账均不由本技能自动完成。
